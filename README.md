# AniGap — Random Video Chat

AniGap is a simple way to start spontaneous conversations with new people through random video chat and text messaging.

**This repository is a public product showcase only.** It contains a bilingual promotional website and illustrative interface previews. It does not contain the website backend, Android source code, server code, secrets, credentials, or deployment configuration.

- **Website:** https://anigap.ir/
- **Telegram:** https://t.me/anigap_ir
- **Android app:** [Download page / releases](https://github.com/pesarakloo/AniGap/releases)

## Features

- Random video conversations
- Text chat
- Simple camera and microphone controls
- English-first page with a Persian language toggle
- Responsive layout for mobile and desktop

## Publish the landing page

1. Open **Settings → Pages** in this repository.
2. Choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.

## Android download

The landing page links to the GitHub Releases area. To enable direct APK downloads, publish a release and attach the official Android APK as a release asset. Do not commit the APK or application source into this repository.

## Security boundary

Only public-facing marketing assets belong here. Never upload application or server source code, `.env` files, credentials, database dumps, private keys, or signing-key backups.
