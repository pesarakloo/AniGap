# AniGap — Random Video Chat

AniGap is a simple way to start spontaneous conversations with new people through random video chat and text messaging.

**This repository is a public product showcase only.** It contains a bilingual landing page and a brand icon. It does not contain application source code, server source code, credentials, secrets, or deployment configuration.

- **Website:** https://anigap.ir/
- **Telegram:** https://t.me/anigap_ir
- **Android app / Releases:** https://github.com/pesarakloo/AniGap/releases

## Features

- Random video conversations
- Text chat
- Simple camera and microphone controls
- English-first landing page with a visible Persian language button
- Responsive layout for mobile and desktop

## Publish the landing page

1. Open **Settings → Pages** in this repository.
2. Choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.

## Android download

Use GitHub Releases to publish the official Android APK. Attach the signed APK as a release asset; do not commit the APK or application source into this repository.

## Security boundary

Only public-facing product information and the brand icon belong here. Never upload application or server source code, `.env` files, credentials, database dumps, private keys, or signing-key backups.
